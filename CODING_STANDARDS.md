# Coding standards

This repo follows two files. Both are part of its standard:

1. `spec/standards/CODING_STANDARDS.md` holds the rules for every Gatepost repo.
2. `spec/standards/languages/typescript.md` holds the rules for TypeScript.

Rules for this repo only: the site is not a package, so it has no change files, no changelog and no API report. Its commits use no scope, as in the spec repo (GIT-1).
