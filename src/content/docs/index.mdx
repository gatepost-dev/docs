On 1 October 2026, NIPOST launched a digital postcode for addressable buildings and locations in Nigeria. A postcode such as `EK-01-A03-FK-01` has five segments. From large to small, they are the state, the LGA, the district, the area and the unit. The unit is one building.

Gatepost helps apps, websites and online stores accept these postcodes.

- Check the form of a postcode offline, with no API key and no network call.
- Clean typed or pasted input: spaces, dashes, full-width characters and invisible characters.
- Suggest a fix for a common typo, such as the letter O where a zero belongs.
- Recognise an old 6-digit postcode.
- Ask NIPOST's gateway about a postcode with your own API key.

Only NIPOST's gateway can say whether a building has a given postcode. Gatepost checks the form first, so your app calls the gateway less often and with clean input.

Gatepost is independent. NIPOST did not make it and does not support it. For a problem with NIPOST's own app, data or API, contact NIPOST through its official website.

The [readiness tracker](readiness/) lists the common tools that still reject the new postcode, and the state of the fix for each one. The [privacy page](privacy/) says what this site stores.
